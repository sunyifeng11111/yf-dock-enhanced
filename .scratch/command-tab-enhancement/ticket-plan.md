## 任务清单

### 01. 打通 Command+Tab 与最小化恢复

**Blocked by:** None (can start immediately).

**交付结果：** 在当前桌面，通过真实 Command+Tab 打开基础窗口面板，跨应用或在同应用内选择具体窗口；松开 Command 后准确激活目标，最小化窗口在确认后恢复。

**验收重点：**

- 基础面板复用已有玻璃／毛玻璃、中性选中态，先使用应用图标与标题即可完整切换；不等待缩略图、完整多行布局或使用历史。
- 实际窗口分别列出，正常无标题窗口保留，同名窗口身份不混淆；浏览器标签页、无窗口应用、重复条目和内部辅助窗口排除。
- 支持 Tab、Shift+Tab、首尾循环、Command 松开确认和 Esc 取消；浏览不恢复窗口、不抢焦点，确认只执行一次。
- 默认开启的独立持久化偏好与基础菜单栏开关可用；关闭后取消选择、恢复系统快捷键；旧 Dock 两项关闭不停止仍启用的增强。
- 缺辅助功能权限或接管创建失败时保留系统行为；确认事件不被原有键盘活动取消逻辑误取消。
- 用两个受控应用及同应用多个窗口验证真实选择、最小化恢复与具体窗口焦点，不以应用激活或模拟调用冒充成功。
- 建立完整选择流程的主要行为检查入口，后续各项在该入口扩展；首次真实路径不可行时记录证据，不宣布完成。

**本项边界：** 当前桌面的基础可用版本。02 扩展特殊窗口范围，03 完成日常交互，04 完成图像与设置，05 处理综合异常并整体验收。

### 02. 支持隐藏、跨桌面和全屏窗口

**Blocked by:** 01.

**交付结果：** 同一切换器能到达隐藏应用、其他桌面、其他显示器和全屏中的具体窗口。

**验收重点：**

- Command+H 隐藏应用后，正常窗口仍可列出；浏览／取消不解除隐藏，确认后指定窗口可见并获焦点。
- 覆盖隐藏与最小化叠加，不将二者混淆；不额外承诺解除应用隐藏时仍单独保留其其他窗口隐藏状态。
- 尽早验证同一应用两个窗口分处不同桌面，以及普通窗口与全屏窗口双向切换、跨显示器选择。
- 分别记录枚举、实际选中、目标可见性和准确焦点，不以卡片出现或应用激活代替切换完成。
- 不因目标处于全屏／其他桌面而将其静默过滤；不改变原 Dock 点击对全屏窗口沿用系统行为的规则。
- 使用基础图标／标题面板即可独立验证，不等待 03 或 04。
- 受平台限制无法满足范围时提供可复现证据及备选方案，需要改变范围再找用户确认；缺必要环境记为检查不可用，不能宣布全部通过。

### 03. 完成排序、多行面板与键鼠交互

**Blocked by:** 01.

**交付结果：** 获得日常完整切换体验：快速按键返回上一个窗口，持续按住才显示统一风格的多行面板，键鼠均可选择和确认。

**验收重点：**

- 跨应用和同应用窗口分别按实际最近使用排序；正向首次选择上一个窗口，支持最近两个窗口往返；浏览、最小化或激活请求返回成功不改写真实使用历史。
- 启动时当前窗口优先，其余无历史窗口按应用名、标题稳定排序，同名／改名不混淆；选择中冻结顺序；历史只存运行内存，重启清空。
- 快速结束不闪面板，持续约 0.12 秒才展示；旧计时在取消后不能重新显示；Tab 长按遵循系统重复节奏。
- 面板位于工作窗口屏幕中央，无前台窗口时使用鼠标屏幕，选择中位置不变；承载屏幕消失时安全取消。
- 多行排列、超出后纵向滚动，卡片保持可辨尺寸，选中项自动滚入可见区域；方向键按几何邻居移动。
- Enter、鼠标点击、Command 松开均只确认一次；Esc／外部点击取消；未被增强使用的输入不被无故屏蔽。
- 键鼠共享选中项，实际移动鼠标才参与选择，面板出现或键盘滚动不让静止指针抢选。
- 玻璃／毛玻璃、圆角、字体、居中标题、中性选中态、对称间距及减少动态效果与原小预览窗一致，保留可访问名称和选中信息。
- 图标／标题即可验收，不依赖 04 的截图；通过完整行为场景、真实输入与桌面合成截图验证排序、计时和视觉。

### 04. 完成缩略图、独立设置与权限降级

**Blocked by:** 01.

**交付结果：** 窗口卡片异步补齐截图，最小化窗口显示缓存与状态；用户可从新设置页管理增强，三个开关独立且状态准确。

**验收重点：**

- 先可操作，再补图；缓存／异步截图不改变身份、顺序、选中项和滚动目标，宽竖图片居中且保持比例。
- 最小化窗口不为截图而恢复，显示最近缓存或应用图标，并低调标注“已最小化”。
- 无录屏权限仍可用图标与标题切换；撤销后清可见图片与缓存，使在途截图失效；重新授权可异步补图。
- 截图有界、只存内存；由仍启用的悬停预览或增强共同使用，关闭其中一项不破坏另一项，两者均关后停止采集并清缓存。
- 新增“窗口切换”设置页，保留原两页、默认页、底部状态、重开入口和自启行为；菜单栏同步开关与保存状态。
- 升级时新偏好未设置默认开启，显式关闭持久化，不覆盖旧偏好；三项全关停止服务并清理待执行动作。
- 验证三个开关全部八种组合、重启持久化和权限状态，区分“增强可用”“控制能力不足”与“仅无截图”；共享 Dock 服务运行不代表增强已接管。
- 更新权限用途和按键识别说明，不记录输入文本、图片或窗口使用历史到磁盘，不在每次切换时重复弹授权。
- 基础面板即可检验图像与设置，不以 02／03 为阻塞前提；同时回归旧 Dock 小预览窗的截图与开关行为。

### 05. 处理异常并完成整体验收

**Blocked by:** 02, 03, 04.

**交付结果：** 窗口变化、恢复失败或快捷键监听中断时不会误切、卡住或被旧恢复抢焦点；完整用户路径与原 Dock 功能通过联合检查，并有准确的兼容性记录。

**验收重点：**

- 关闭窗口移除，选中项关闭后顺延且其余顺序不变；新窗口下轮加入；覆盖空列表、仅当前窗口、唯一非当前候选及失效身份。
- 覆盖全部确认方式，确认自身事件不误取消必要恢复，后续新活动使旧激活失效；旧计时／重试／回调不重新显示或抢焦点。
- 恢复失败给简短非阻塞提示，不代选其他窗口、不无限重试。
- 监听超时／禁用、辅助功能权限丢失或松键事件丢失后清理旧会话，检查后续完整快捷键可用；不承诺重放全部已拦截输入。
- 验证增强关闭／无法接管时的系统回退、安全输入与其他快捷键工具的实际边界；可重复注入的故障自动化，其余记录真实环境结果。
- 组合验证最近使用顺序、最小化／隐藏、跨桌面／全屏、键鼠确认、图像与权限变化；修复分支合并后才出现的问题。
- 各前置项已有自身检查，本项不承接它们所有基本测试；补齐联合检查，并核对全部 62 条用户故事及规格验证要求。
- 回归旧 Dock 点击、悬停、右键菜单、拖动、修改键点击、设置重开、自启与功能开关；原全屏 Dock 点击边界保持。
- 实测冷／热启动、多应用、慢枚举、无图响应和约 0.12 秒展示目标；对照明暗、多行／滚动、横竖图、显示器缩放和减少动态效果的实际桌面合成截图。
- 更新使用和验证记录，缺权限、显示器、系统版本或夹具记为未验证／检查不可用，不冒充通过。恢复测试前台、鼠标及窗口状态，不采集用户内容、不自动替换已安装应用或发布。
