# 04: 完成缩略图、独立设置与权限降级

**What to build:** 窗口卡片异步补齐截图，最小化窗口显示缓存与状态；用户可从新设置页管理增强，三个开关独立且状态准确。

Blocked by: 01

Status: ready-for-agent

## Acceptance criteria

- [ ] 先可操作，再补图；缓存／异步截图不改变身份、顺序、选中项和滚动目标，宽竖图片居中且保持比例。
- [ ] 最小化窗口不为截图而恢复，显示最近缓存或应用图标，并低调标注“已最小化”。
- [ ] 无录屏权限仍可用图标与标题切换；撤销后清可见图片与缓存，使在途截图失效；重新授权可异步补图。
- [ ] 截图有界、只存内存；由仍启用的悬停预览或增强共同使用，关闭其中一项不破坏另一项，两者均关后停止采集并清缓存。
- [ ] 新增“窗口切换”设置页，保留原两页、默认页、底部状态、重开入口和自启行为；菜单栏同步开关与保存状态。
- [ ] 升级时新偏好未设置默认开启，显式关闭持久化，不覆盖旧偏好；三项全关停止服务并清理待执行动作。
- [ ] 验证三个开关全部八种组合、重启持久化和权限状态，区分“增强可用”“控制能力不足”与“仅无截图”；共享 Dock 服务运行不代表增强已接管。
- [ ] 更新权限用途和按键识别说明，不记录输入文本、图片或窗口使用历史到磁盘，不在每次切换时重复弹授权。
- [ ] 基础面板即可检验图像与设置，不以 02／03 为阻塞前提；同时回归旧 Dock 小预览窗的截图与开关行为。

## Scope and context

本任务属于用户已确认的 Command+Tab 增强第一版，窗口切换器（Window switcher）按具体窗口而非应用分组；选中窗口（Selected window）只是待确认目标，浏览不应改变真实焦点。

主要用户故事：1–2、46–50、58–61。

完整产品约束见[已确认规格](../spec.md)，术语以根 GLOSSARY 为准。不同显示器／桌面／应用的结果应按真实环境记录；若能力不能满足已确认范围，提供具体证据与备选方案，再确认必要范围变化，不静默删减目标。

## Validation

通过可重复场景验证异步图像及权限变化、三个开关全部八种组合和偏好迁移；在基础真实面板及设置中确认图片、状态与持久化结果，回归旧小预览窗。

测试关注用户可观察行为，优先复用现有行为检查与原生窗口夹具；不以内部字段或仅收到调用代替行为成功。缺权限、显示器或系统环境时记录检查不可用／未验证，不记作通过。原生检查应恢复测试前鼠标、前台与窗口状态，不采集真实用户内容。

本任务不授权自动替换已安装应用或发布；完成本项并不代表全部增强功能或所有系统环境已通过。
