## Acceptance criteria

- [x] 先可操作，再补图；缓存／异步截图不改变身份、顺序、选中项和滚动目标，宽竖图片居中且保持比例。
- [x] 最小化窗口不为截图而恢复，显示最近缓存或应用图标，并低调标注“已最小化”。
- [x] 无录屏权限仍可用图标与标题切换；撤销后清可见图片与缓存，使在途截图失效；重新授权可异步补图。
- [x] 截图有界、只存内存；由仍启用的悬停预览或增强共同使用，关闭其中一项不破坏另一项，两者均关后停止采集并清缓存。
- [x] 新增“窗口切换”设置页，保留原两页、默认页、底部状态、重开入口和自启行为；菜单栏同步开关与保存状态。
- [x] 升级时新偏好未设置默认开启，显式关闭持久化，不覆盖旧偏好；三项全关停止服务并清理待执行动作。
- [x] 验证三个开关全部八种组合、重启持久化和权限状态，区分“增强可用”“控制能力不足”与“仅无截图”；共享 Dock 服务运行不代表增强已接管。
- [x] 更新权限用途和按键识别说明，不记录输入文本、图片或窗口使用历史到磁盘，不在每次切换时重复弹授权。
- [ ] 基础面板即可检验图像与设置，不以 02／03 为阻塞前提；同时回归旧 Dock 小预览窗的截图与开关行为。
