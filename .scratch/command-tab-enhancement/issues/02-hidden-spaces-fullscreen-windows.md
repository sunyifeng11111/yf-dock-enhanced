# 02: 支持隐藏、跨桌面和全屏窗口

**What to build:** 同一切换器能到达隐藏应用、其他桌面、其他显示器和全屏中的具体窗口。

Blocked by: 01

Status: ready-for-agent

Resolution: pending scope confirmation — cold-start full-screen discovery gap; ordinary-desktop / multi-display validation outstanding

## Acceptance criteria

- [x] Command+H 隐藏应用后，正常窗口仍可列出；浏览／取消不解除隐藏，确认后指定窗口可见并获焦点。
- [x] 覆盖隐藏与最小化叠加，不将二者混淆；不额外承诺解除应用隐藏时仍单独保留其其他窗口隐藏状态。
- [ ] 尽早验证同一应用两个窗口分处不同桌面，以及普通窗口与全屏窗口双向切换、跨显示器选择。
- [x] 分别记录枚举、实际选中、目标可见性和准确焦点，不以卡片出现或应用激活代替切换完成。
- [x] 不因目标处于全屏／其他桌面而将其静默过滤；不改变原 Dock 点击对全屏窗口沿用系统行为的规则。
- [x] 使用基础图标／标题面板即可独立验证，不等待 03 或 04。
- [x] 受平台限制无法满足范围时提供可复现证据及备选方案，需要改变范围再找用户确认；缺必要环境记为检查不可用，不能宣布全部通过。

## Scope and context

本任务属于用户已确认的 Command+Tab 增强第一版，窗口切换器（Window switcher）按具体窗口而非应用分组；选中窗口（Selected window）只是待确认目标，浏览不应改变真实焦点。

主要用户故事：8–12。

完整产品约束见[已确认规格](../spec.md)，术语以根 GLOSSARY 为准。不同显示器／桌面／应用的结果应按真实环境记录；若能力不能满足已确认范围，提供具体证据与备选方案，再确认必要范围变化，不静默删减目标。

## Validation

使用基础面板真实执行隐藏、最小化、跨桌面、全屏与跨显示器选择，逐一核实目标窗口身份、可见性和焦点。模拟检查只证明规则，不证明系统兼容性。

测试关注用户可观察行为，优先复用现有行为检查与原生窗口夹具；不以内部字段或仅收到调用代替行为成功。缺权限、显示器或系统环境时记录检查不可用／未验证，不记作通过。原生检查应恢复测试前鼠标、前台与窗口状态，不采集真实用户内容。

本任务不授权自动替换已安装应用或发布；完成本项并不代表全部增强功能或所有系统环境已通过。
