**What to build:** 窗口变化、恢复失败或快捷键监听中断时不会误切、卡住或被旧恢复抢焦点；完整用户路径与原 Dock 功能通过联合检查，并有准确的兼容性记录。

## Acceptance criteria

- [x] 关闭窗口移除，选中项关闭后顺延且其余顺序不变；新窗口下轮加入；覆盖空列表、仅当前窗口、唯一非当前候选及失效身份。
- [x] 覆盖全部确认方式，确认自身事件不误取消必要恢复，后续新活动使旧激活失效；旧计时／重试／回调不重新显示或抢焦点。
- [x] 恢复失败给简短非阻塞提示，不代选其他窗口、不无限重试。
- [x] 监听超时／禁用、辅助功能权限丢失或松键事件丢失后清理旧会话，检查后续完整快捷键可用；不承诺重放全部已拦截输入。
- [x] 验证增强关闭／无法接管时的系统回退、安全输入与其他快捷键工具的实际边界；可重复注入的故障自动化，其余记录真实环境结果。
- [x] 组合验证最近使用顺序、最小化／隐藏、跨桌面／全屏、键鼠确认、图像与权限变化；修复分支合并后才出现的问题。
- [x] 各前置项已有自身检查，本项不承接它们所有基本测试；补齐联合检查，并核对全部 62 条用户故事及规格验证要求。
- [ ] 回归旧 Dock 点击、悬停、右键菜单、拖动、修改键点击、设置重开、自启与功能开关；原全屏 Dock 点击边界保持。
- [ ] 实测冷／热启动、多应用、慢枚举、无图响应和约 0.12 秒展示目标；对照明暗、多行／滚动、横竖图、显示器缩放和减少动态效果的实际桌面合成截图。
- [x] 更新使用和验证记录，缺权限、显示器、系统版本或夹具记为未验证／检查不可用，不冒充通过。恢复测试前台、鼠标及窗口状态，不采集用户内容、不自动替换已安装应用或发布。

## Scope and context

本任务属于用户已确认的 Command+Tab 增强第一版，窗口切换器（Window switcher）按具体窗口而非应用分组；选中窗口（Selected window）只是待确认目标，浏览不应改变真实焦点。

主要用户故事：51–57，以及全部 62 条故事的联合结果与原功能回归。

完整产品约束见[已确认规格](../spec.md)，术语以根 GLOSSARY 为准。不同显示器／桌面／应用的结果应按真实环境记录；若能力不能满足已确认范围，提供具体证据与备选方案，再确认必要范围变化，不静默删减目标。

## Validation

在既有完整选择流程入口注入窗口变化和故障，覆盖全部确认路径，再以真实恢复与监听场景检查后续输入和焦点。各前置任务须已有自己的检查，本项补齐联合场景、性能、视觉及回归记录。

测试关注用户可观察行为，优先复用现有行为检查与原生窗口夹具；不以内部字段或仅收到调用代替行为成功。缺权限、显示器或系统环境时记录检查不可用／未验证，不记作通过。原生检查应恢复测试前鼠标、前台与窗口状态，不采集真实用户内容。

本任务不授权自动替换已安装应用或发布；完成本项并不代表全部增强功能或所有系统环境已通过。
