# 03: 完成排序、多行面板与键鼠交互

**What to build:** 获得日常完整切换体验：快速按键返回上一个窗口，持续按住才显示统一风格的多行面板，键鼠均可选择和确认。

Blocked by: 01

Status: ready-for-agent

## Acceptance criteria

- [ ] 跨应用和同应用窗口分别按实际最近使用排序；正向首次选择上一个窗口，支持最近两个窗口往返；浏览、最小化或激活请求返回成功不改写真实使用历史。
- [ ] 启动时当前窗口优先，其余无历史窗口按应用名、标题稳定排序，同名／改名不混淆；选择中冻结顺序；历史只存运行内存，重启清空。
- [ ] 快速结束不闪面板，持续约 0.12 秒才展示；旧计时在取消后不能重新显示；Tab 长按遵循系统重复节奏。
- [ ] 面板位于工作窗口屏幕中央，无前台窗口时使用鼠标屏幕，选择中位置不变；承载屏幕消失时安全取消。
- [ ] 多行排列、超出后纵向滚动，卡片保持可辨尺寸，选中项自动滚入可见区域；方向键按几何邻居移动。
- [ ] Enter、鼠标点击、Command 松开均只确认一次；Esc／外部点击取消；未被增强使用的输入不被无故屏蔽。
- [ ] 键鼠共享选中项，实际移动鼠标才参与选择，面板出现或键盘滚动不让静止指针抢选。
- [ ] 玻璃／毛玻璃、圆角、字体、居中标题、中性选中态、对称间距及减少动态效果与原小预览窗一致，保留可访问名称和选中信息。
- [ ] 图标／标题即可验收，不依赖 04 的截图；通过完整行为场景、真实输入与桌面合成截图验证排序、计时和视觉。

## Scope and context

本任务属于用户已确认的 Command+Tab 增强第一版，窗口切换器（Window switcher）按具体窗口而非应用分组；选中窗口（Selected window）只是待确认目标，浏览不应改变真实焦点。

主要用户故事：17–18、22、25–28、30–45、62。

完整产品约束见[已确认规格](../spec.md)，术语以根 GLOSSARY 为准。不同显示器／桌面／应用的结果应按真实环境记录；若能力不能满足已确认范围，提供具体证据与备选方案，再确认必要范围变化，不静默删减目标。

## Validation

在完整选择流程入口使用模拟时间与输入序列验证排序、快速切换、取消和键鼠选择，再用真实输入、实际网格及桌面合成截图验证响应、位置、滚动和视觉。

测试关注用户可观察行为，优先复用现有行为检查与原生窗口夹具；不以内部字段或仅收到调用代替行为成功。缺权限、显示器或系统环境时记录检查不可用／未验证，不记作通过。原生检查应恢复测试前鼠标、前台与窗口状态，不采集真实用户内容。

本任务不授权自动替换已安装应用或发布；完成本项并不代表全部增强功能或所有系统环境已通过。
