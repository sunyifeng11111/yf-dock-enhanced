# 01: 打通 Command+Tab 与最小化恢复

**What to build:** 在当前桌面，通过真实 Command+Tab 打开基础窗口面板，跨应用或在同应用内选择具体窗口；松开 Command 后准确激活目标，最小化窗口在确认后恢复。

Blocked by: None (can start immediately)

Status: ready-for-agent

Resolution: completed

## Acceptance criteria

- [x] 基础面板复用已有玻璃／毛玻璃、中性选中态，先使用应用图标与标题即可完整切换；不等待缩略图、完整多行布局或使用历史。
- [x] 实际窗口分别列出，正常无标题窗口保留，同名窗口身份不混淆；浏览器标签页、无窗口应用、重复条目和内部辅助窗口排除。
- [x] 支持 Tab、Shift+Tab、首尾循环、Command 松开确认和 Esc 取消；浏览不恢复窗口、不抢焦点，确认只执行一次。
- [x] 默认开启的独立持久化偏好与基础菜单栏开关可用；关闭后取消选择、恢复系统快捷键；旧 Dock 两项关闭不停止仍启用的增强。
- [x] 缺辅助功能权限或接管创建失败时保留系统行为；确认事件不被原有键盘活动取消逻辑误取消。
- [x] 用两个受控应用及同应用多个窗口验证真实选择、最小化恢复与具体窗口焦点，不以应用激活或模拟调用冒充成功。
- [x] 建立完整选择流程的主要行为检查入口，后续各项在该入口扩展；首次真实路径不可行时记录证据，不宣布完成。

## Scope and context

本任务属于用户已确认的 Command+Tab 增强第一版，窗口切换器（Window switcher）按具体窗口而非应用分组；选中窗口（Selected window）只是待确认目标，浏览不应改变真实焦点。

主要用户故事：3–7、13–16、19–21、23–24、29，以及 41、51、58 的基础能力。

当前桌面的基础可用版本。02 扩展特殊窗口范围，03 完成日常交互，04 完成图像与设置，05 处理综合异常并整体验收。

完整产品约束见[已确认规格](../spec.md)，术语以根 GLOSSARY 为准。不同显示器／桌面／应用的结果应按真实环境记录；若能力不能满足已确认范围，提供具体证据与备选方案，再确认必要范围变化，不静默删减目标。

## Validation

沿用现有 DockCoreChecks 的行为检查形式，围绕完整选择流程断言选中、取消和唯一确认结果；以受控同应用／跨应用窗口真实按键验证指定窗口恢复和焦点。必要的局部职责整理先行，避免单独创建横向重构任务。

测试关注用户可观察行为，优先复用现有行为检查与原生窗口夹具；不以内部字段或仅收到调用代替行为成功。缺权限、显示器或系统环境时记录检查不可用／未验证，不记作通过。原生检查应恢复测试前鼠标、前台与窗口状态，不采集真实用户内容。

本任务不授权自动替换已安装应用或发布；完成本项并不代表全部增强功能或所有系统环境已通过。
