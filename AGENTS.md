## Agent skills

### Issue tracker

Track specs and implementation issues in local Markdown under `.scratch/`. Before reading or creating tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles. Before assigning a triage status, read `docs/agents/triage-labels.md`.

### Domain docs

Use one root `GLOSSARY.md` and `docs/adr/`. Before exploring domain behavior, read `docs/agents/domain.md` and any existing relevant domain docs.
